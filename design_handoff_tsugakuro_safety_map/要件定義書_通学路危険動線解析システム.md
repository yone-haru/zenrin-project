## 0. システム概要

出発地・目的地を指定してルート検索すると、そのルート上の危険地点をピンで表示するWebアプリ。

**コアフロー**
```
ユーザーがA地点→B地点を指定
→ OSRMでルート取得
→ ルート上の交差点・地点を抽出
→ OSM道路構造データ＋警察庁事故データで危険スコア算出
→ 地図上にルートライン＋危険地点ピンを表示
```

**技術スタック**

| レイヤー | 採用技術 |
|---|---|
| フロントエンド | React + TypeScript + Leaflet |
| バックエンド | FastAPI（Python 3.11+） |
| ルート取得 | OSRM API（OpenStreetMap） |
| 道路構造データ | OSM Overpass API |
| 事故データ | 警察庁交通事故オープンデータ（CSV） |
| 地図タイル | OpenStreetMap（MVP） → ゼンリン（後で差し替え） |

## 2. データモデル

class HazardPoint(BaseModel):
    id: str                  # UUID
    latitude: float
    longitude: float
    risk_score: int          # 1〜5（TODO: スコアリング詳細は後で詰める）

```python
class RouteResponse(BaseModel):

```

## 3. APIエンドポイント仕様

### POST `/api/route` — ルート検索＋危険地点取得

**Request Body**

```json
{
  "origin": {
    "lat": 32.7503,
    "lng": 129.8777,
    "address": "長崎市立〇〇小学校"  // 任意（表示用）
  },
  "destination": {
    "lat": 32.7601,
    "lng": 129.8690,
    "address": "〇〇町1-2-3"  // 任意（表示用）
  }
}
```

**処理フロー**

```
1. OSRMにorigin→destinationのルートをリクエスト
2. ルートのGeoJSON LineStringを取得
3. ルート上の交差点・ノードを一定間隔（例: 50mごと）でサンプリング
4. 各サンプル地点周辺（半径50m）のOverpass APIで道路構造タグを取得
5. 各サンプル地点周辺（半径50m）の事故データをaccidents.csvから検索
6. scoring.pyで危険スコアを算出（TODO: 詳細後で詰める）
7. risk_score >= 2 の地点のみHazardPointとして返す
8. RouteResponseを返す
```

**Response** `200 OK`

```json
{
  "route_geometry": {
    "type": "LineString",
    "coordinates": [[129.8777, 32.7503], [129.8750, 32.7520], "..."]
  },
  "distance_m": 1250.5,
  "duration_s": 980,
  "hazard_points": [
    {
      "id": "uuid",
      "latitude": 32.7520,
      "longitude": 129.8750,
      "risk_score": 4,
      "risk_factors": ["歩道なし", "事故多発"],
      "accident_count": 3,
      "osm_tags": { "highway": "secondary", "sidewalk": "none" }
    }
  ]
}
```

### GET `/api/geocode` — 住所→緯度経度変換

住所テキスト入力からピン指定に変換するためのエンドポイント。

**Query Parameters**

| パラメータ | 型 | 説明 |
|---|---|---|
| `q` | string | 住所テキスト（例: "長崎市栄町1-1"） |

**処理**

Nominatim API（OSM）を使って緯度経度に変換して返す。

**Response** `200 OK`

```json
{
  "lat": 32.7503,
  "lng": 129.8777,
  "display_name": "長崎市栄町1-1, 長崎県"
}
```

## 5. フロントエンド実装仕様

### SearchPanel.tsx

- 出発地・目的地の入力方法を2つ提供
